# 🏎️ ApexRush

ApexRush is a fast-paced endless highway racing game where players race through dynamic tracks, dodge traffic, collect coins, unlock powerful cars, upgrade performance, complete missions, and compete for the highest score.

## 🎮 Features

- 🏁 Endless highway racing gameplay
- 🚗 Multiple unlockable cars
- ⚡ Engine, handling, and brake upgrades
- 🛣️ Multiple racing tracks
- 🌤️ Different driving conditions
- 💰 Coin collection and reward system
- 🎯 Missions and challenges
- 🏆 Global leaderboard
- 💾 Persistent player progress
- 🔐 Secure anonymous player sessions
- ☁️ Cloudflare D1 database integration
- 🚀 Deployed using Cloudflare Workers
- 📱 Responsive modern arcade-style UI

## 🚘 Available Cars

- Rookie GT
- Comet
- Vortex
- Phantom

Each car has different speed, handling, braking performance, and upgrade options.

## 🗺️ Tracks

ApexRush includes multiple racing environments such as:

- Sunset Highway
- City
- Desert
- Forest
- Snow

## 🎯 Missions

Players can complete challenges such as:

- Pass 20 vehicles
- Survive for 120 seconds
- Collect 30 coins
- Complete near-miss challenges

Completing missions rewards additional coins.

## 🏆 Leaderboard

Players can compete for the highest score. The leaderboard stores and displays the best-performing racers using Cloudflare D1.

## 💡 How It Works

1. A player opens ApexRush.
2. A unique player session is created.
3. The player selects a track and car.
4. The race starts.
5. The player dodges traffic and collects coins.
6. Race statistics are validated by the backend.
7. Coins, scores, missions, and garage progress are saved.
8. Best scores appear on the leaderboard.
